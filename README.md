## The word

**irregardless**

The dictionary deleting a word that was never really a word: a double
negative ("ir-" plus "-less") that only survives in dictionaries with a
"nonstandard" warning taped to it. Erasing it is the dictionary
correcting its own typo — the joke lands the moment the word is gone,
with no setup needed. Fresh, too: the field reaches first for "moist"
and "literally".

## How it works

`main.py` writes exactly one word, and nothing else, to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), which the
bounty judge reads head-to-head against the other entries.

```sh
python3 main.py
```
